# Real Life

Landing para proyecto de hábitos de vida: entrenamiento, nutrición y bienestar emocional.

Sitio estático (HTML/CSS/JS sin build), cuatro páginas:

- `index.html` — portada
- `viva-la-vida.html` — hábitos diarios y bienestar emocional
- `nutricion.html` — nutrición
- `entrenamiento.html` — entrenamiento (gimnasio o calistenia)

Estilos compartidos en `styles.css`, interacción en `script.js`.

## Ver en local

```bash
python3 -m http.server 8000
```

Y abrir `http://localhost:8000`.
